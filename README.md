# sprint7-final-project
Data Analyst tripleten bootcamp, sprint 7 final project

**Objetivo del Proyecto**
Se presentan datos de la empresa ConnectaTel, empresa de telecomunicaciones con operaciones en Mexico y Colombia, el objetivo del notebook es entender la segmentacion de sus usuarios, patrones de uso y las diferentes necesidades que pueda tener cada segmento.

**Datasets Utilizados**
Para este análisis se utilizaron 3 datasets, se presentan listados a continuación:
  - plans.csv
  - users_latam.csv
  - usage.csv

**Etapas del análisis**
los pasos seguidos para este análisis fueron los siguientes:
- Carga y exploración de datos
- Identificación de problemas de calidad en los datos
- Detección de valores inválidos y sentinels
- Limpieza básica de los datos
- Resumen estadístico
- Visualización de distribuciones
- Segmentacion de clientes
- Hallazgos
